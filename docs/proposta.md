# Problema

Ao planejar uma viagem ou até mesmo um “rolê” com os amigos, pessoas acabam perdendo tempo tentando lembrar quem pagou o que, e muitas vezes se confundem na hora de acertas as despesas compartilhadas.

# Solução

Splito. Um sistema que registra os gastos e diz quem deve pagar quanto para quem, com o mínimo de transferências possíveis.

# Público Alvo

- Grupos de amigos e família.
- Pessoas que irão organizar viagens com muitas pessoas.

# Histórias de Usuário

- Como usuário, quero criar um grupo e adicionar participantes, para organizar os gastos.
- Como participante, quero registrar uma despesa informando quem pagou e quem participou, para dividir o valor.
- Como usuário, quero ver o saldo de cada pessoa, para saber quem deve e quem recebe.
- Como usuário, quero ver a lista final de transferências, para quitar tudo com o mínimo de pagamentos.
